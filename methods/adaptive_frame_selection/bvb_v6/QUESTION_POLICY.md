# 逐题保留策略扩展

本目录是在学长 V6 固定版本上做的本地扩展；检测、聚类和场景资产协议仍沿用原流程。`question_policy.py` 根据公开题目类型和文本给出暂定策略，支持题目显式 `retention_policy` 覆盖。它不是官方数据集标签，无法理解所有表达，存在歧义时返回 `unknown`。

- `single`：每个目标类别通常只需要一份实例。单类别中多个候选审核通过时，要求逐题比较，再选择一组；相同类别的多个题目角色自动标为未知。所有候选都明确误检时阻止重建，不能为了凑齐类别把误检当真。
- `multiple`：保留审核通过和待确认的候选，不因同类别就强制合并为一个；明确误检的候选剔除。候选组不是实例数，重建后还需处理跨组重复。
- `supplemental`：静态场景之外还需要时序、相机或运动证据；默认阻止把静态草图当成完整重建，显式 `--allow-incomplete-evidence` 才可制作草图。
- `unknown`：暂时沿用旧规则并保留状态，不能当作已经解决该题。

先执行 `python -m bvb_v6.semantic_review prepare` / `submit` 完成语义审核，再执行 `python -m bvb_v6.coverage prepare`、必要时 `submit`、`export`，最后用导出的 `reviewed-selection.json` 执行 `python -m bvb_v6 prepare`。审核未完成、覆盖不完整或所有候选被拒绝时明确阻止，结果包含原因和证据。新的类型判断不改变已有实验缓存；历史审核继续绑定原提示词哈希。

共同坐标系只是要求每组根据输入位姿输出到同一个世界系，默认合并程序使用单位变换拼接，**不会验证模型是否正确遵从坐标，也不会自动对齐或跨组去重**。可选的 [多帧联合校正](MULTIFRAME_ALIGNMENT.md) 在既有拼合后单独生成候选，不能保证位置正确。投影检查可作为诊断，但检测框、深度、位姿均可能出错；`coverage_complete` 只说明候选覆盖，并不证明几何准确、数目正确或问题能被回答。

可对已经生成场景的每组运行 `python -m bvb_v6.reprojection_check --prepared /path/to/prepared --out /path/to/report.json`。该检查把目标中心投回同组原帧，观察是否落进同类别检测框；没有框的帧不计入，摄像机背后的点标为无投影。同类多个物体只要任一中心落进框就算该框命中，因此不能用于确认实例身份。检测框、位姿和物体都可能出错，必须结合原帧和同机位重拍检查。
